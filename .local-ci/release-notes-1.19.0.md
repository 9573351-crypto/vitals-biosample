## 生息样本库 1.19.0 · 修复自动更新不可用

### 本次修复

**问题**：v1.18.2 的发布物是打包方提供的原始 APK，其中**不含更新模块**；且当时不存在比 1.18.2 更新的版本。因此侧边栏没有「检查更新」能力，即使有也只会显示「已是最新」——自动更新实际不可用。

**修复内容**：

1. **本版本首次真正内置更新模块**（`updater.js` / `VitalsUpdater` / FileProvider），安装本版后即可在应用内检查并安装后续版本。
2. **当前版本显示更可靠**：原生在 `checking` / `checked` 事件中直接带回本机版本，不再依赖同步桥取值；同步桥失败时依次回退到界面构建标记与页面自报版本，避免出现「当前版本未知」从而误判为检测失败。
3. **失败原因可诊断**：区分超时、DNS 解析失败、TLS 失败、连接被拦截、GitHub 限流等情形并给出对应提示，同时写入 Android 日志（tag `VitalsUpdate`），不再是笼统的「检查更新失败」。
4. **安装前校验签名一致性**：覆盖安装要求同一签名，现在会在交给系统安装器之前先比对，签名不符时直接给出「请先导出备份后卸载旧版本再安装」的明确提示，而不是让系统只报一句「应用未安装」。
5. 修复 `build-apk.ps1`：版本号改为从 `app/build.gradle` 读取，不再写死文件名与 JDK 路径。

### 安装须知

- **签名**：本 APK 使用本机构建调试签名。若设备上已安装的 1.18.2 是打包方原始签名，则与本包签名不同，**无法直接覆盖安装**——请先导出备份、卸载旧版，再安装本包。应用在后续版本中会自己检查并提示该情况。
- 从本版开始，只要后续 Release 始终使用同一签名，即可在应用内一键升级。
- 卸载会清除本机数据，操作前请先在「设置」中导出备份。
